# Energy-Disaggregation
Energy Disaggregation and Analytics for Behind-the-Meter PV, HVAC, and EV Charging Loads

## Instructions

### 1. Clone Repository

### 2. Navigate to `main` branch. This is the most up-to-date working version.

### 3. Download data folder, add to local clone.

### 4. Create Conda environment

- Navigate to repo location
- Create conda environment using `conda env create -f environment.yml`

### 5. Run `data_generation` notebook.

### 6. Run  `feature_extraction` and `data_analysis` notebook.
